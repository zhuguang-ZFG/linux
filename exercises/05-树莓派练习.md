# 树莓派支线 · 练习题与答案

对应 [树莓派支线](../docs/05-raspberry-pi/01-树莓派是什么与选购.md)。没有设备时可完成概念题和软件模拟，实物接线与供电验证仍需实际硬件。

## 一、概念题

1. Pico 能直接运行本教程的 Raspberry Pi OS 吗？
2. `LED(17)` 的 17 是物理第 17 针吗？
3. LED 可以不串联电阻直接接 GPIO 吗？
4. Samba 共享目录等于独立备份吗？
5. 摄像头打不开与 OCR 识别错误，是同一类问题吗？

<details><summary>答案</summary>

1. 不能，Pico 是微控制器开发板，编程与部署方式不同。
2. 不是，它是 BCM GPIO17，对应 Pi 4/5 40 针排针的物理第 11 针。
3. 不可以，本实验要求串联限流电阻，并在断电后接线。
4. 不等于，误删或存储故障会影响共享数据，需要独立副本与恢复验证。
5. 不是，前者先检查设备、权限和占用，后者检查图像质量、参数与模型。
</details>

## 三、无硬件时的模拟题

在安装 gpiozero 的 Python 环境中，用 MockFactory 验证 LED 的软件状态；它不能验证物理针脚、供电与接线：

```python
from gpiozero import Device, LED
from gpiozero.pins.mock import MockFactory

Device.pin_factory = MockFactory()
with LED(17) as led:
    led.on()
    assert led.value == 1
    led.off()
    assert led.value == 0
print("software logic passed")
```

<details><summary>如何解释结果</summary>

输出只证明 on/off 改变了模拟引脚状态。真实板子还可能接错针脚、LED 极性反了或权限不足，不能将模拟通过写成硬件验证通过。
</details>
