# 阶段 1 · 基础篇练习

对应 [文件与目录操作](../docs/01-basics/01-文件与目录操作.md) 至 [求助方法](../docs/01-basics/08-高效求助-man与tldr.md)。

## 一、概念题（5 题）

1. `chmod 640 file` 给所有者、组和其他人什么权限？
2. Vim 中保存退出与放弃修改退出分别是什么？
3. `apt update` 是否升级已安装软件？
4. 默认 `kill PID` 与 `kill -9 PID` 有什么区别？
5. 普通变量与 `export` 后的变量，对子进程可见性有何区别？

<details><summary>答案</summary>

1. 所有者读写，组只读，其他人无权限。目录的 x 还表示可进入/遍历，不能照搬普通文件语义。
2. Esc 后 `:wq` 保存退出，`:q!` 放弃退出。
3. 不升级，只刷新包索引；升级用 upgrade。
4. 默认发送 TERM，程序可处理并清理；KILL 无法捕获，只作为最后手段。
5. export 后进入子进程环境；子进程修改自己的环境不会自动改回父 Shell。
</details>

## 二、实操题（5 题）

所有操作放在独立实验目录，避免覆盖自己的文件：

```bash
basic_lab=$(mktemp -d)
mkdir "$basic_lab/source" "$basic_lab/restored"
printf 'Linux\nBash\nLinux\n' > "$basic_lab/source/names.txt"
```

1. 把 names.txt 复制成一个带空格的文件名，证明内容相同。
2. 把副本权限改成 640，用 `ls -l` 解释结果。
3. 把 source 打包到实验目录，解压到 restored，验证内容。
4. 启动 `sleep 300` 后台任务，只终止自己刚启动的进程。
5. 创建普通变量与环境变量，让子 Bash 打印并比较。

<details><summary>参考解法</summary>

```bash
cp "$basic_lab/source/names.txt" "$basic_lab/source/names copy.txt"
cmp "$basic_lab/source/names.txt" "$basic_lab/source/names copy.txt"
chmod 640 "$basic_lab/source/names copy.txt"
ls -l "$basic_lab/source/names copy.txt"
tar -czf "$basic_lab/source.tar.gz" -C "$basic_lab" source
tar -xzf "$basic_lab/source.tar.gz" -C "$basic_lab/restored"
cmp "$basic_lab/source/names.txt" "$basic_lab/restored/source/names.txt"
sleep 300 &
sleep_pid=$!
kill "$sleep_pid"
LOCAL_DEMO=local
export EXPORTED_DEMO=exported
bash -c 'printf "local=%s exported=%s\n" "${LOCAL_DEMO-unset}" "$EXPORTED_DEMO"'
```

cmp 无输出且返回 0 表示一致；最后输出 `local=unset exported=exported`。用 `man cmp` 查退出码含义。
</details>
