# 阶段 0 · 启蒙认知练习

对应 [启蒙认知章节](../docs/00-onboarding/01-为什么人人都要学Linux.md)。先独立回答，再展开答案。

## 一、概念选择

1. Ubuntu 与 Linux 内核的关系是：A 同一个东西；B Ubuntu 是包含内核和用户空间工具的发行版；C Ubuntu 是终端。
2. Windows 用户不改动现有磁盘分区即可练习 Linux 的方式是：A 必须双系统；B WSL 或虚拟机；C 只能买树莓派。
3. Bash 属于：A Shell；B 文件系统；C 包管理器。

<details><summary>答案与解释</summary>

1. B。发行版还包含软件仓库、系统工具与默认配置。
2. B。虚拟机隔离完整系统，WSL 适合与 Windows 协作，具体服务能力取决于配置。
3. A。终端提供交互界面，Shell 解析执行输入，它们不是同一个概念。
</details>

## 二、看命令猜作用（10 组）

先写下作用，判断它是只读还是会改变当前会话/文件，再在测试终端运行。

| # | 命令 |
|---|---|
| 1 | `pwd` |
| 2 | `ls -la` |
| 3 | `cd ~` |
| 4 | `whoami` |
| 5 | `uname -r` |
| 6 | `cat /etc/os-release` |
| 7 | `date` |
| 8 | `printf 'hello\n'` |
| 9 | `mkdir -p ~/linux-first-lab` |
| 10 | `touch ~/linux-first-lab/hello.txt` |

<details><summary>参考答案</summary>

1. 当前工作目录；2. 含隐藏项的详细目录列表；3. 切到家目录；4. 当前用户名；5. 内核版本；6. 发行版标识；7. 当前时间；8. 输出文本；9. 创建目录，已有时不报错；10. 创建空文件或更新已有文件时间。

第 3 组改变当前 Shell 的工作目录，第 9、10 组会改变文件系统，其余这里的用法是读取或输出。
</details>

## 三、实操验收

在 Linux 环境保存一张“环境名片”：

```bash
mkdir -p "$HOME/linux-first-lab"
{ whoami; uname -r; cat /etc/os-release; } > "$HOME/linux-first-lab/environment.txt"
cat "$HOME/linux-first-lab/environment.txt"
```

解释其中哪些字段表示发行版、哪些表示内核。退出终端后再打开，确认文件还在。

- [ ] 概念题全部能解释。
- [ ] 10 组命令至少独立解释 8 组。
- [ ] 能找到环境名片，并区分持久文件与终端会话状态。
