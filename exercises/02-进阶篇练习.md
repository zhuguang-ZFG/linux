## 一、概念题

1. `>out 2>&1` 和 `2>&1 >out` 为什么不同？
2. `grep`、`sed`、`awk` 各适合解决什么问题？
3. `systemctl start` 与 `enable` 的区别是什么？
4. 磁盘剩余容量充足却不能新建文件，还应检查什么？
5. 备份目录有 5 份归档时，预演新增一份应计划删除几份？

<details><summary>答案</summary>

1. 重定向按从左到右处理；前者把标准输出和错误都指向文件，后者的错误保留原标准输出目的地。
2. grep 筛选匹配行；sed 对文本流做替换等变换；awk 适合字段、条件和统计。
3. start 立即启动，enable 设置自动启动；需要同时执行可用 enable --now。
4. `df -i` 的 inode、配额、权限和只读挂载等。
5. 1 份。新备份必须占一个位置；归档成功后才真正删旧文件。
</details>

## 二、日志分析实操

```bash
text_lab=$(mktemp -d)
cat > "$text_lab/access.log" <<'EOF'
192.0.2.1 GET / 200
192.0.2.2 GET /missing 404
192.0.2.1 GET /about 200
192.0.2.3 POST /login 403
EOF
```

任务：找出 4xx 行；把 `/missing` 替换为 `/gone` 输出到新文件；统计每个 IP 请求次数，次数降序排列。

<details><summary>参考解法与预期</summary>

```bash
awk '$4 >= 400 && $4 < 500' "$text_lab/access.log"
sed 's|/missing|/gone|g' "$text_lab/access.log" > "$text_lab/rewritten.log"
awk '{count[$1]++} END {for (ip in count) print count[ip], ip}' "$text_lab/access.log" | sort -nr
```

4xx 有 2 行；新文件包含 `/gone`，原文件不变；192.0.2.1 有 2 次，另外两个地址各 1 次。
</details>
