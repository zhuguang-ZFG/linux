# 权限与用户速查

数字与符号是同一件事的两种写法；改权限前先想清「谁需要、需要什么、范围多大」。

## 权限位

| 写法 | 含义 | 备注 |
|---|---|---|
| `r` = 4 / `w` = 2 / `x` = 1 | 读/写/执行 | 三组相加 |
| `755` = `rwxr-xr-x` | 属主全权，其余读+执行 | 目录/可执行文件常见 |
| `644` = `rw-r--r--` | 属主读写，其余只读 | 普通文件常见 |
| `600` = `rw-------` | 仅属主读写 | 私钥、含密码配置 |
| `700` = `rwx------` | 仅属主全权 | 个人目录 |
| `777` | 所有人全权 | **几乎总是错的** |

## rwx 对目录的特殊含义

| 位 | 对文件 | 对目录 |
|---|---|---|
| `r` | 读内容 | 列出名字（`ls`） |
| `w` | 改内容 | 增删改名（需同时有 `x`） |
| `x` | 执行 | **进入/穿过**（能否 `cd`、访问子项） |

## 常用命令

| 目的 | 命令 |
|---|---|
| 看权限 | `ls -l`；`stat 文件` |
| 符号改法 | `chmod u+x 文件`；`chmod go-w 文件` |
| 数字改法 | `chmod 640 文件`；`chmod -R 750 目录` |
| 换属主/组 | `sudo chown 用户:组 文件`；`chgrp 组 文件` |
| 默认权限 | `umask`；`umask 027`（当前会话） |
| 特殊位 | `chmod u+s`（SUID）、`g+s`（SGID）、`+t`（sticky） |

## 用户与组

| 目的 | 命令 |
|---|---|
| 当前身份 | `id`；`whoami`；`groups` |
| 建用户（含家目录） | `sudo useradd -m -s /bin/bash 用户名`；`sudo passwd 用户名` |
| 改/删用户 | `sudo usermod -aG 组 用户`；`sudo userdel -r 用户` |
| 查看用户清单 | `getent passwd`；`getent group` |
| 切换身份 | `su - 用户`；`sudo -u 用户 命令`；`sudo -i` |

## sudo 与提权

| 目的 | 命令 |
|---|---|
| 查看被授权范围 | `sudo -l` |
| 以其他用户执行 | `sudo -u www-data 命令` |
| 编辑 sudoers（**必须**） | `sudo visudo`（或 `visudo -f /etc/sudoers.d/文件名`） |
| 免密（谨慎） | `用户名 ALL=(ALL) NOPASSWD: /usr/bin/systemctl restart nginx` |

## 特殊位与 ACL

| 目的 | 命令 | 说明 |
|---|---|---|
| SUID | `chmod u+s 程序` | 以属主身份运行（如 `passwd`） |
| SGID（目录） | `chmod g+s 目录` | 新文件继承目录组 |
| sticky（目录） | `chmod +t /tmp` | 只有属主能删自己的文件 |
| ACL 查看 | `getfacl 文件` | 比 rwx 更细的授权 |
| ACL 授权 | `setfacl -m u:alice:rw 文件` | 给特定用户单独权限 |
| 不可变属性 | `lsattr 文件`；`sudo chattr +i 文件` | 连 root 都不能改（除属性） |

## 检查清单

- [ ] 改权限前用 `ls -ld` 确认当前状态
- [ ] 目录需要访问权限时，`x` 与 `r` 要一起考虑
- [ ] 私钥与含密码文件保持 `600`
- [ ] 用 `sudo visudo` 而不是直接编辑 `/etc/sudoers`
- [ ] 共享目录优先用组 + SGID，而不是 777
