# Vim 速查

先按 Esc 回到普通模式，再输入下面的普通模式命令。

| 目的 | 按键 |
|---|---|
| 插入 / 行尾追加 | `i` / `A` |
| 新建下一行并插入 | `o` |
| 移动 | `h j k l` 或方向键 |
| 行首 / 行尾 | `0` / `$` |
| 文件首 / 文件尾 | `gg` / `G` |
| 下一个词 | `w` |
| 删除当前行 | `dd` |
| 复制当前行 / 粘贴 | `yy` / `p` |
| 撤销 / 重做 | `u` / Ctrl-R |
| 搜索 / 下一个结果 | `/关键词` 回车 / `n` |
| 显示行号 | `:set number` |
| 保存 / 保存退出 | `:w` / `:wq` |
| 放弃修改退出 | `:q!` |
| 全文替换并逐次确认 | `:%s/旧/新/gc` |

不要把 `:q!` 当成保存命令；不确定自己在哪个模式时先按 Esc。参考 [Vim 章节](../docs/01-basics/02-查看与编辑文件-Vim.md)。
