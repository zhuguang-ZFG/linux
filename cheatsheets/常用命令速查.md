# 常用命令速查

以下路径、PID 和包名按实际替换。涉及删除或权限变更，先确认目标。

| 目的 | 命令 |
|---|---|
| 当前目录 / 详细列表 | `pwd` / `ls -lah` |
| 创建目录 | `mkdir -p -- 目录` |
| 复制 / 移动 | `cp -- 源 目标` / `mv -- 源 目标` |
| 查看文件前后 20 行 | `head -n 20 文件` / `tail -n 20 文件` |
| 分页查看 | `less 文件`（q 退出） |
| 查找普通文件 | `find 目录 -type f -name '*.txt'` |
| 比较内容 | `cmp 文件1 文件2` |
| 用户身份 | `id` |
| 普通文件仅自己读写 | `chmod 600 文件` |
| 目录仅自己访问 | `chmod 700 目录` |
| 查看进程 | `ps aux` / `top` |
| 请求进程结束 | `kill PID`（先确认 PID） |
| 磁盘容量 / inode | `df -h` / `df -i` |
| 目录大小 | `du -sh 目录` |
| 打包 / 列出内容 | `tar -czf 包.tar.gz 目录` / `tar -tzf 包.tar.gz` |
| 解压到已有空目录 | `tar -xzf 包.tar.gz -C 目标目录` |
| 刷新索引 / 安装 | `sudo apt update` / `sudo apt install 包名` |
| 查看命令来源 | `command -v 命令` |
| 查手册 | `man 命令` / `命令 --help` |

变量作为路径时用 `"$path"`；`--` 防止以连字符开头的文件名被解释为选项，但不能替代目标核对。参考 [基础篇](../docs/01-basics/01-文件与目录操作.md)。
