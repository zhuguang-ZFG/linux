# 网络速查

| 层次/目的 | 命令 |
|---|---|
| 接口与地址 | `ip -br address` |
| 路由 | `ip route` |
| DNS 解析 | `getent ahosts example.com` |
| TCP 监听 | `ss -ltn` |
| 监听进程 | `sudo ss -ltnp` |
| HTTP 头与超时 | `curl -I --max-time 10 https://example.com` |
| SSH 调试 | `ssh -v 用户@主机` |
| 公钥生成 | `ssh-keygen -t ed25519`（不覆盖已有密钥） |
| 复制公钥 | `ssh-copy-id 用户@主机` |
| 指定 SSH 端口 | `ssh -p 2222 用户@主机` |
| scp 指定端口 | `scp -P 2222 文件 用户@主机:目录/` |
| 预演同步 | `rsync -av --dry-run 源目录/ 用户@主机:目标目录/` |
| SSH 本地隧道 | `ssh -N -L 127.0.0.1:8080:127.0.0.1:80 用户@主机` |

主机指纹变化要先核实；ping 失败不等于 TCP 不通；超时、拒绝连接、认证失败分别属于不同排查方向。参考 [网络章节](../docs/02-advanced/08-网络基础与远程连接.md)。
