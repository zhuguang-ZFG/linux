# grep / sed / awk 速查

| 目的 | 命令 |
|---|---|
| 按字面量搜索并显示行号 | `grep -nF '文本' 文件` |
| 扩展正则 / 不区分大小写 | `grep -Ei 'error|warn' 文件` |
| 反向匹配 | `grep -v '^#' 文件` |
| 显示上下文 | `grep -C 2 '关键字' 文件` |
| 替换后输出，不改原件 | `sed 's/old/new/g' 文件` |
| 备份后原地替换 | `sed -i.bak 's/old/new/g' 文件` |
| 删除空行后输出 | `sed '/^$/d' 文件` |
| 打印第 1、3 列 | `awk '{print $1, $3}' 文件` |
| 以逗号作简单分隔 | `awk -F, '{print $2}' 文件` |
| 数值列求和 | `awk '{sum += $2} END {print sum}' 文件` |
| 统计第一列频次 | `awk '{print $1}' 文件 | sort | uniq -c | sort -nr` |

带引号或内嵌换行的 CSV 应使用 CSV 解析器，不直接按逗号切分。传递文件名用 NUL 分隔，例如：

```bash
find ./notes -type f -name '*.txt' -print0 | xargs -0 -r grep -nF -- 'Linux'
```

`./notes` 要替换成实际存在的目录。不要把 `ls` 输出直接交给 `xargs rm`；空格、引号和换行会改变参数边界。参考 [进阶篇](../docs/02-advanced/01-管道与重定向.md)。
