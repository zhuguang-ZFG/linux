# 树莓派速查

以下硬件命令面向 Raspberry Pi OS，普通 PC/容器未必提供这些接口。

| 目的 | 命令/要点 |
|---|---|
| 型号 | `tr -d '\0' < /proc/device-tree/model` |
| CPU 架构 | `uname -m`（本支线用 aarch64） |
| 系统版本 | `cat /etc/os-release` |
| 配置菜单 | `sudo raspi-config` |
| 网络状态 | `nmcli device status`（使用 NetworkManager 时） |
| 温度 | `vcgencmd measure_temp` |
| 欠压/限频状态 | `vcgencmd get_throttled`（位掩码含历史状态） |
| 引脚图 | `pinout` |
| GPIO17 | BCM 17，Pi 4/5 的物理第 11 针 |
| GPIO27 | BCM 27，Pi 4/5 的物理第 13 针 |
| 地线 | 本实验用物理第 6 针 GND |
| USB 视频设备 | `v4l2-ctl --list-devices` |
| 检查共享实际存储 | `findmnt -T /srv/pi-share` |
| 正常关机 | `sudo poweroff` |

接线前断电，GPIO 使用 3.3V 逻辑，LED 串限流电阻。不要把信号引脚接到 5V，不直接驱动电机。参考 [GPIO 章节](../docs/05-raspberry-pi/04-GPIO硬件编程.md) 和 [支线练习](../exercises/05-树莓派练习.md)。
