# 容器速查

| 目的 | 命令 |
|---|---|
| 拉取镜像 | `docker pull 镜像:标签` |
| 查看本地镜像 | `docker images` |
| 后台运行容器 | `docker run -d --name 名称 -p 8080:80 -v 卷名:/数据目录 镜像` |
| 进入容器执行 | `docker exec -it 名称 bash` |
| 查看运行中容器 | `docker ps`（加 `-a` 看已停止的） |
| 查看日志 | `docker logs -f 名称` |
| 停止容器 | `docker stop 名称` |
| 删除容器 | `docker rm 名称` |
| 删除无用镜像 | `docker rmi 镜像ID` |
| 一键清理 | `docker system prune -af`（会删所有未使用资源，先确认） |
| Compose 启动 | `docker compose up -d` |
| Compose 停止并删卷 | `docker compose down -v`（卷数据一并删除，先确认） |
| 查看端口映射 | `docker port 名称` |
| 查看资源占用 | `docker stats` |

容器里的进程与数据都随生命周期管理：数据要持久化就挂卷，端口映射用 `-p 宿主机:容器`，修改配置后重建容器而不是在容器里手工改。参考 [容器与虚拟化章节](../docs/03-pro/04-容器与虚拟化.md)。
