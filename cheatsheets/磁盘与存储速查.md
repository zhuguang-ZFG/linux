# 磁盘与存储速查

读数字先问「看的是哪一层」：容量、inode、还是实际写入速度？

## 看容量与空间

| 目的 | 命令 | 要点 |
|---|---|---|
| 文件系统用量 | `df -h`；`df -i` | `-i` 看 inode（小文件多会先满） |
| 谁占最多 | `du -x -h --max-depth=1 路径 \| sort -h` | `-x` 不跨文件系统 |
| 目录总大小 | `du -sh 目录` | 大目录较慢，可加 `-x` |
| 已删除但占用 | `lsof +L1` | 进程还开着被删文件 |
| 设备与挂载 | `lsblk -o NAME,SIZE,TYPE,FSTYPE,UUID,MOUNTPOINTS` | 脚本用 UUID，不写死设备名 |

## 分区与文件系统

| 目的 | 命令 | 要点 |
|---|---|---|
| 查看分区表 | `sudo fdisk -l`；`sudo parted -l` | 只读查看，改前备份 |
| 建文件系统 | `sudo mkfs.ext4 /dev/sdX1` | **会清空该分区** |
| 检查/修复 | `sudo fsck /dev/sdX1` | 必须先卸载 |
| 查看 UUID | `blkid` | 写进 `/etc/fstab` |
| 查看文件系统类型 | `findmnt -T 路径` | 问「这个路径落在哪」 |

## 挂载

| 目的 | 命令 | 要点 |
|---|---|---|
| 临时挂载 | `sudo mount /dev/sdX1 /mnt/data` | 重启后消失 |
| 按 UUID 挂载 | `sudo mount UUID=xxxx /mnt/data` | 稳定写法 |
| 卸载 | `sudo umount /mnt/data` | 忙时先 `lsof +D 挂载点` |
| 开机自动挂载 | `sudoedit /etc/fstab` | 加 `nofail` 防启动失败；改后 `sudo mount -a` 验证 |
| 写入缓冲落盘 | `sync` | 拔除设备前执行 |

## 归档与压缩

| 目的 | 命令 |
|---|---|
| 打包（不压缩） | `tar cf backup.tar 目录/` |
| 打包 + gzip | `tar czf backup.tar.gz 目录/` 或 `tar cf - 目录 \| gzip > backup.tgz` |
| 查看内容 | `tar tzf backup.tar.gz` |
| 解包到指定目录 | `tar xzf backup.tar.gz -C /目标` |
| 排除文件 | `tar czf a.tgz --exclude='*.log' 目录/` |
| 单文件压缩 | `gzip file`；`gunzip file.gz`；`xz -9 file` |

## 磁盘性能与健康

| 目的 | 命令 | 要点 |
|---|---|---|
| 顺序读吞吐 | `dd if=/dev/zero of=test.bin bs=1M count=512 oflag=direct` | 测试文件要删 |
| 简单读写基准 | `fio --name=t --rw=randwrite --size=256M --filename=/tmp/fio.test` | 生产慎用 |
| 使用率与延迟 | `iostat -xz 1` | 看 `%util` 与 `await` |
| SMART 健康 | `sudo smartctl -a /dev/nvme0` | 看 `Percentage Used`、错误计数 |
| TRIM | `sudo fstrim -v /`；`systemctl status fstrim.timer` | SSD 定期回收 |

## 空间不足的四步排查

1. `df -h /`：哪个文件系统满
2. `df -i /`：是否 inode 耗尽
3. `du -x --max-depth=1 路径 | sort -h`：哪个目录大
4. `lsof +L1`：是否有「已删除但占用」的大文件

四步都做完再决定清理动作；**永远先备份，再删除**。
