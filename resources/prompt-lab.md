# 提示词练习：让 AI 帮你提出可验证的问题

以下为本项目原创模板，可用于你已有的 AI 助手或 [本地模型](../docs/04-projects/项目4-Linux跑本地AI.md)。不要求注册特定产品，也不要求把真实生产数据发送到外部服务。

## 1. 命令解释卡

```text
我正在学习 Linux，环境是：[发行版、工具版本]。
请解释这条命令：[命令]。
逐个说明参数、输入、标准输出、错误输出和退出码。
标明是否会写文件或修改系统，是否依赖 GNU 扩展。
给一个只在新建临时目录中运行的最小实验，并说明预期结果。
遇到不确定的版本差异请说明，不要凭空补参数。
```

**练习**：用 grep 有匹配、无匹配和文件不存在三种情况核对退出码。模型答案与本机手册冲突时，以实际适用的手册和实验为依据。

## 2. 报错分析卡

```text
目标：[想完成的操作]。
环境：[发行版、容器/虚拟机/物理机、权限、相关版本]。
命令与错误：[经过脱敏的最小输出]。
已排除的情况：[证据]。
请分成：已知事实、可能原因、缺少的信息。
最多给三条只读检查命令，每条说明它能支持或否定哪个假设。
在证据不足前，不建议删除、改权限、关闭防火墙或重启。
```

**练习**：对比“端口被占用”和“认证失败”，检查模型是否选了不同的第一步。

## 3. 脚本审阅卡

```text
以下脚本只应处理：[明确目录/文件范围]。
输入格式和业务约束：[说明]。
请检查空参数、空格/换行文件名、失败退出、重复执行和并发。
逐条给出：触发条件、可能影响、最小修复与回归测试。
不要直接运行脚本，不扩大操作范围，不隐藏失败。
脚本：[粘贴已移除密码和真实地址的最小代码]。
```

**练习**：解释为什么 `ls | xargs rm` 不能可靠处理任意文件名，再读 [备份实现](../scripts/backup.sh) 和 [回归测试](../scripts/backup.test.mjs)。

## 4. 学习复盘卡

```text
这是我的实验记录：[环境、操作、实际结果、未解决问题]。
请帮我整理成：目标、关键概念、证据、常见误解、下一步。
不要把推测写成事实，不要把示例输出写成我的实测输出。
最后提出三道可用本地实验验证的自测题，答案折叠在最后。
```

**练习**：把整理后的笔记交给不了解过程的人，让对方只凭记录复做。复现不出来的地方，就是需要补充的上下文。

## 如何评价回答

| 检查项 | 我找到的证据 |
|---|---|
| 是否识别了当前环境与版本 | 填实际句子或缺漏 |
| 是否区分事实与假设 | 填示例 |
| 命令是否超出目标范围 | 填路径、权限和副作用 |
| 是否有可核对的依据 | 填手册条目与适用版本 |
| 是否完成本地复验 | 填命令和实际结果 |

先完成 [AI 辅助学习章节](../docs/03-pro/07-AI辅助学习与运维.md)，再把有效模板与证据整理为自己的笔记。模型可能给错答案；练习目标是提高核对能力。
